
# ShaadiGo.com - Wedding & Event Management System

## Introduction

**ShaadiGo** is a comprehensive web-based platform designed to simplify the management, booking, and coordination of wedding halls and event services. The system centralizes complex logistics into a single interface, allowing customers to browse venues and check real-time availability while providing venue owners with efficient tools for operational management.

---

## Core Functionalities

### For Customers

* **User Authentication:** Secure registration and login for personalized services.


* **Venue Discovery:** Browse available venues via organized booking cards and high-quality image galleries.


* **Advanced Search:** Filter venues by location, price range, capacity, and availability.


* **Booking Management:** Create, view, and track the status of event bookings.


* **Availability Calendar:** View a dynamic calendar for each venue to prevent scheduling conflicts.


* **Payments & Refunds:** Secure online payments/deposits with a transparent refund process for eligible cancellations.


* **Communication:** Real-time chat system to message venue owners directly for inquiries and negotiations.


* **Feedback:** Rate and review venues after event completion to help future users.



### For Venue Owners & Admins

* **Operational Tracking:** Monitor upcoming and "In Progress" events in real-time.


* **Cancellation Management:** Handle cancellations according to predefined policies with automatic status updates.


* **Analytical Insights:** Access statistical reports on peak booking months and demand trends.


* **Support Module:** Manage customer inquiries, feedback, or complaints through a dedicated interface.



---

## System Goals

1. **Centralization:** Provide a single platform for all wedding-related logistics and stakeholder communication.


2. **Efficiency:** Optimize resource utilization for venue managers during peak seasons.


3. **Transparency:** Ensure clear financial transactions and booking statuses for both parties.
